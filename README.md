# EduPro Instructor Performance Dashboard

This project evaluates instructor performance and course quality using analytics and machine learning.

## Features
- KPI Dashboard
- Instructor Leaderboard
- Experience vs Rating Analysis
- Course Quality Trends
- Streamlit Web App

## Tech Stack
Python, Pandas, Seaborn, Scikit-learn, Streamlit

## Run Locally
pip install -r requirements.txt
streamlit run app.py
